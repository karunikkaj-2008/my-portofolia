# CSE Student Portfolio Website

A responsive portfolio website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and placeholder social-link notice

## Preview locally
Open `index.html` in a web browser.

## Publish using GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your website.

## Before publishing
- Replace the placeholder `#` URLs for GitHub and LinkedIn in `index.html` with your actual profile links.
- Review your public email and location to make sure you are comfortable sharing them.
- Google Fonts is used for typography; the page still works if it cannot load.
